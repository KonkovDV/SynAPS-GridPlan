## 1. Что на самом деле оценивает акселератор

Программа рассчитана на университетские научно-инженерные разработки преимущественно УГТ 3–5.
Отбор: формальная проверка → оценка техноброкером → оценка потенциальным заказчиком.
Проект включается **только при наличии значимого для компании сценария применения**.

**Критерии финала (Демо-день, 10 проектов, грант МФТИ 1,5 млн руб.):**

1. Научная и технологическая значимость
2. Перспективность промышленного сценария и эффект для заказчика
3. Обоснованность и реализуемость дорожной карты трансфера
4. Качество условий перехода между уровнями ТРЛ
5. Реалистичность компетенций, инфраструктуры, партнёров и финансирования
6. Готовность ближайшего следующего этапа к запуску

> Положение не задаёт веса критериев: шкала утверждается организатором.
> Любые придуманные баллы нельзя выдавать за официальный регламент.

### Соответствие SynAPS-GridPlan критериям

| Критерий | Что уже есть | Что нужно доказать |
|---|---|---|
| Технологическая значимость | Детерминированный solver, независимый checker, audit log, Python/Rust parity | Новизну относительно CP-SAT, MILP; формализовать класс задач |
| Промышленный сценарий | Демо планирования работ и ресурсов | Один конкретный процесс, владелец, цена ошибки |
| Дорожная карта | Публичный backlog и архитектура | Этапы ТРЛ 4→5→6 с критериями |
| Переходы ТРЛ | Воспроизводимый лабораторный стенд | Подписанный shadow-пилот |
| Ресурсная модель | Open-source MIT | Роли доменного эксперта, интегратора; план open-core |
| Следующий этап | Shadow-пилот | Письмо интереса, данные, GO/NO-GO |

## 2. Аудит репозитория v0.1.8

**Проверен:** HEAD `c42417d5` (18 сентября 2026 г.)

### Сильные стороны

- Разделение generator/checker снижает риск «самопроверки».
- Fail-closed семантика и явный exit code полезны для CI и on-prem.
- Публично описаны ограничения: синтетические данные, отсутствие deployment.
- Python/Rust parity и 183/48 тестов (commit-доказательство в `AUDIT.md`).
- Консистентные pin-версии 0.1.8 во всех файлах. ✅

### Технические вопросы, которые задаст сильный эксперт

1. **Completeness.** P(решение) = 1 не доказан.
2. **Complexity.** Требуется честная оценка worst-case и scaling plot.
3. **Objective.** FEASIBLE ≠ optimal.
4. **Constraint coverage.** Нужна таблица: бизнес-правило → формула → checker → тест.
5. **Independent baseline.** CP-SAT baseline требуется на тех же данных.
6. **Security.** Нужны threat model, access controls, audit log.

## 4. Рекомендуемое позиционирование

### Ключевой тезис

> SynAPS-GridPlan — детерминированный и аудируемый движок поддержки планирования
> производственных работ. Он преобразует формализованные ограничения
> площадки в воспроизводимый график, а независимый checker не допускает
> выдачу результата при нарушении жёстких правил. На следующем
> этапе хотим вместе с индустриальным заказчиком проверить
> применимость на обезличенных данных реального объекта.

### Нейросимволическая схема (для направления «агентная автоматизация»)

1. ИИ-ассистент извлекает черновые ограничения и объясняет конфликт на языке пользователя
2. Пользователь подтверждает формализованный JSON
3. Детерминированный solver строит вариант
4. Независимый checker принимает или блокирует
5. Человек утверждает публикацию

> ИИ не должен менять жёсткие ограничения или публиковать расписание самостоятельно.

## 5. Shadow-пилот ТРЛ 4→5

| Этап | Работа | Критерий |
|---|---|---|
| 1. Контракт данных | Словарь полей, hard/soft constraints | Подписанный data/constraint contract |
| 2. Baseline | Исторический график + ручной/FIFO на том же горизонте | Время, нарушения, churn |
| 3. Адаптация | Коннектор, доменный профиль правил | Все правила трассируются в checker и тесты |
| 4. Shadow run | ≥20 периодов, infeasible cases | Воспроизводимый протокол |
| 5. Приёмка | Разбор с дисп., ИТ и ИБ; GO/NO-GO | Решение о пилоте |

**Метрики:** 100% hard constraints; ноль known violations; доля feasible; p50/p95; schedule churn; доля принятых без перестройки.

**Смета гранта 1,5 млн руб.:**

| Статья | Сумма |
|---|---|
| Доменная формализация + данные | 300 тыс. |
| Solver/checker + тесты | 350 тыс. |
| Интеграция + on-prem | 300 тыс. |
| ИБ + документация | 200 тыс. |
| Проведение пилота | 200 тыс. |
| IP + резерв | 150 тыс. |
| **Итого** | **1 500 тыс.** |
