# Масштаб генератора (синтетический фидер)

Не РЭС «Северный» и не месячная кампания ДЗО. Случайные окна и квалификации:
это стенд **времени поиска** и того, что независимый чекер на размере не молчит.

Проверенный макет кампании — `jury_report.md` (55 работ, GREED 0 нарушений).

Локальный прогон 18.08.2026, Python 3.13, пин SynAPS `bd09d13`. Время стены
плавает; в CI гоняется только форма (200 работ, `tests/test_scale_feeder.py`).
Режим `stress` (600) в CI не запускается — около четырёх минут.

| Режим | Работ | GREED назначил | Жёстких нарушений | Проверка | Стена GREED+чекер |
| --- | ---: | ---: | ---: | --- | --- |
| `medium` seed=12 | 200 | 200 | 17 | нет | ~10 с (поиск ~1,5 с) |
| `stress` seed=12 | 600 | 600 | 56 | нет | ~4 мин (поиск ~65 с) |

Чекер на 200 и 600 не маркирует план как `verified_feasible`. Это fail-closed
на размере, **не допустимый месячный график**.

Прогоны 50k/500k в README движка SynAPS — другой домен (не постановка ТОиР).
`feasibility_rate` оттуда на GridPlan не переносится.

```bash
python -m synaps_gridplan synthesize --mode medium --seed 12 -o medium.json
python -m synaps_gridplan solve medium.json --solver GREED -o medium-plan.json
# exit 2 — чекер отверг, это ожидаемо
```
