# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.4 | best effort |

## Reporting a vulnerability

Use GitHub Security Advisories on this repository.

This tree does not contain customer operational data. Fixtures are labelled
`data_provenance=synthetic`. Do not file live grid dumps, credentials, or
named DZO extracts as issues or pull requests.
