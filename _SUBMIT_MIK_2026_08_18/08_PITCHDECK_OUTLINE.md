# 03 — Питчдек (12 слайдов): ремонтная кампания сети

> Аудитория: **ПАО «Россети»** / МИК. Критерии: внедрение / применимость / зрелость.
> Зрелость на слайдах = **ISO 16290 TRL 4**. Не писать «УГТ 5→6».

## 1. Титул
SynAPS-GridPlan. «График ТОиР и заявок ПЛ — проверяемый, воспроизводимый, без замены вашей АСУ».

## 2. Проблема
Ремонтная кампания сети: бригады × окна отключения × ЗИП × уже согласованные ПЛ. Сборка в Excel / EAM без комбинаторной проверки. Цена: срыв окна, конфликт двух отключений, ручной хаос при аварии.

## 3. Ниша одной схемой
`Журнал дефектов / ППР → [SynAPS-GridPlan] → АСУ ТОиР / согласование ПЛ`  
Мы — вычислительный слой, не «ещё одна 1С» и не диагностика.

## 4. Решение
Вход: активы, работы, бригады, окна, ЗИП, заморозка, явные bans.  
Выход: график + протокол проверки. Нарушение ⇒ план не «пройден».  
Поиск: GREED / CP-SAT. Чекер: Python + Rust.

## 5. Почему white-box
Согласование ПЛ и надзор требуют: тот же вход → тот же график; список нарушенных правил; статус `heuristic_feasible` vs `optimal` без подмены.

## 6. Для Россетей (основной слайд заказчику)
Пилот: один РЭС / ПО. Автоматизация процесса планирования ремонтной кампании.  
KPI: время сборки графика; 0 сдвигов замороженных ПЛ; доля планов без жёстких нарушений чекера.  
Не обещаем SAIDI и N-1.

## 7. Тираж (не второй центр заявки)
ЭЛ5-Энерго: тот же слой на блоке ГРЭС / ВЭС. СберСити / Интер РАО — не слайд «равного» заказчика.

## 8. Живое демо
Сценарий A: синтетический РЭС «Северный» из README (55 работ, 7 бригад). FIFO ломается, GREED проходит проверку. Срочная + freeze ПЛ. Скринкаст 3 мин (`28_SCREENCAST_3MIN.md`). См. `07_DEMO_SCENARIOS.md`.

## 9. Зрелость
ISO 16290 **TRL 4** (лаборатория). Публичный репозиторий 0.1.1, пин SynAPS `bd09d13`, автотесты `pytest -q`, `jury_report.md`.  
Порог марафона — TRL 4+ ([Leader-ID](https://leader-id.ru/navigator/1717)).  
Переход на TRL 5–6 — данные ДЗО и тень на площадке. Внедрения нет.

## 10. Конкуренты честно
Мировые: Maximo Optimizer, Hexaly @ ČEZ. В РФ класса нет. Т1 «Орсима» — generic, без предметки ТОиР сети. In-house ДЗО — АСУ, не этот слой. См. `05`.

## 11. Дорожная карта
Подача 20.08 → День заказчика (Ломоносов, сентябрь) → финал октябрь → пилот П0–П2, 3–6 мес. Тираж: другие ДЗО, затем генерация.

## 12. Запрос (обязателен)
«Пилот на вашем РЭС, 3–6 мес., KPI-протокол. Грант города до ₽4 млн закрывает испытания (смета 410-ПП). Нужны 10 позиций данных и куратор ППР. Не нужен доступ в SCADA».
