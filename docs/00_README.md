## Правила честности

- Не заявлять «аналогов нет» — есть Hexaly @ ČEZ, IBM Maximo Optimizer.
- Не заявлять внедрение, N-1, SAIDI, живые данные ДЗО.
- Крупнейший **ТОиР-инстанс продукта** — 55 работ (РЭС «Северный»). Прогоны 50k/500k — синтетика **другого домена** движка SynAPS.
- ISO 16290 **TRL 4** везде. Не «УГТ 5→6».
- ИНН / ОГРНИП в анкету с кабинета ФНС, не в этот каталог.
