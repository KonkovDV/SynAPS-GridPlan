Этот файл — единственный текущий реестр количественных и нормативных тезисов
для публичных материалов. Исторический каталог `docs/` (кроме этого файла и
указанных ниже текущих) и пакет `_SUBMIT_MIK_2026_08_18/` **не** являются
источником цифр для новой заявки.

Статусы: `verified` — есть первичный источник и воспроизводимый расчёт или
цитата названия; `assumption` — рабочая гипотеза, в тексте должна быть
помечена; `target` — цель следующего этапа, не факт; `withdrawn` — не
повторять.

Нельзя складывать результаты разных датасетов в одну шкалу. Нельзя называть
организацию партнёром или заказчиком продукта без документа в этом реестре.
