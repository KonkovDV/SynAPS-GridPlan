## Этап 3. Выбор одного направления (3 варианта, одна шкала)

Шкала 1–5 по критериям задания. Источник запросов заказчиков: материалы Марафона (`Марафон/2.txt`) + соответствие коду.

| Критерий | 1. Россети (ТОиР / бригады / восстановление) | 2. Интер РАО (диагностика / инспекции) | 3. СберСити (РИЭ / BESS / зарядка) |
|---|---|---|---|
| Соответствие текущему SynAPS (FJSP-SDST-ARC, frozen, RHC, crews-as-WC) | **5** | **3** (их 6 запросов — роботы-осмотрщики; мы не робот) | **2** (нужен TOU/peak/SoC — в коде нет) |
| Убедительное демо без закрытых данных | **5** (синтетическая сеть/бригады) | **3** (без робота демо слабее их запроса) | **2** (без тарифов/профилей нагрузки — натяжка) |
| Понятность заказчику | **5** (график ТОиР — родной язык сетей) | **4** | **4** (но другой класс продукта) |
| Измеримый эффект на синтетике/open data | **5** (просрочки, риск-proxy, простой, churn) | **3** | **3** (без реальных цен — слабые KPI) |
| Реализм пилота после отбора | **4** (интеграция с АСУ ТОиР Россети МР) | **3** (конкурируем с робототехникой на Дне заказчика) | **3** (нужен EMS-контур) |
| **Сумма** | **24 / 25** | **16 / 25** | **14 / 25** |

### Решение (одно, не распылять)

**Основной заказчик / сценарий заявки: «Россети» — риск-ориентированное планирование ТОиР и ремонтных бригад сетевых активов.**

**Рабочее имя продукта:** SynAPS-GridPlan  

**Почему не Интер РАО:** публичные запросы цикла — роботизированная диагностика (6 задач). SynAPS не закрывает осмотр статора/БПЛА. Роль «после диагностики → график» — вторичная строка, не ядро.

**Почему не СберСити:** запрос — накопители и AI-управление энергосистемой. Это требует TOU/peak/SoC-моделей, которых **нет** в коде (`RFC_E_FJSP`: peak/TOU out of scope). Делать вид, что GridPlan = MicroGrid EMS — нарушение правила «не приписывать».

**Связь с ЭЛ5 (из предыдущего пакета gridplan):** ЭЛ5 остаётся **сильным вторым адресатом того же продукта** (генерация = тот же GridPlan), но в рамках **этого ТЗ** выбор между тремя заданными — **Россети**. В заявке Марафона допустимо указать основное направление шире (автоматизация/данные у Россетей) + применимость к ЭЛ5; не плодить три продукта.

### Демо-сценарий v0 (защищаемый без закрытых данных)

**Название:** «Участок распредсети: месячный ППР → авария → перепланирование с frozen».

| Параметр | Значение (синтетика) | Маркировка |
|---|---|---|
| Активы | 40–80 единиц оборудования | синтетические данные |
| Работы | 200–600 операций ТО/ремонта | синтетические |
| Бригады | 8–15 (WorkCenter) | синтетические |
| Квалификации / ЗИП | aux resources (proxy) | синтетические / упрощённо |
| Окна отключений | frozen + due dates | синтетические |
| PoF / критичность | входной score → priority / risk weight | эксперимент (не «инженерное заключение») |
| Базлайны | календарный FIFO, GREED, SynAPS (CPSAT/RHC), repair after fault | эксперимент |
| Метрики | просрочки, risk-proxy, setup/travel proxy, coverage, time, verified_feasible, gap если есть | эксперимент |

**Разрешённые заявления после демо:** «на синтетических данных движок строит feasible график, перепланирует при аварии без сдвига frozen, сравнивает с жадным/календарным».  
**Запрещено:** «пилот», «внедрение», «точность >X%», «оптимум» без dual bound, «экономия ₽N».

## Что подтверждено / что нет

### Подтверждено аудитом
- Ядро SynAPS — зрелый детерминированный планировщик MO-FJSP-SDST-ARC с портфелем и FeasibilityChecker.
- Frozen + RHC + IncrementalRepair пригодны как математическая основа GridPlan.
- Energy_kwh как терм — есть; энерго-онтология ТОиР — нет.
- `synaps_gridplan` ещё не существует.

### Не подтверждено
- Содержимое официального PDF Положения Марафона (скан без текстового слоя) — допуск субъекта уточнять у кураторов.
- Готовность Россетей дать данные до отбора — неизвестно.
- Полный Парето по риск/стоимость/churn — нет в коде.
- Per-assignment XAI — нет в коде.

### Риски этапа
1. На Дне заказчика Россети формулировка широкая («автоматизация, big data») — нужно говорить их языком ТОиР/бригад, иначе утонем среди «оборудования/ИБ».
2. ЗИП и геомаршруты в демо будут **proxy** через aux/SDST — честно маркировать.
3. Смена фокуса с ЭЛ5→Россети требует обновить тексты `docs/gridplan/*` на этапе 10 (не сейчас ломать код).
