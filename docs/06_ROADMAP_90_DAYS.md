## 3. Пилот (после финала, 3–6 месяцев)

Площадка по умолчанию: **РЭС / ПО группы «Россети»**, не ГРЭС ЭЛ5.

| Фаза | Содержание | KPI-протокол |
|---|---|---|
| **П0** (мес. 0–1) | Обезличенная история ППР/ПЛ → ретро: «ваш прошлый график vs GridPlan» | Разрыв по нарушениям чекера, время сборки, 0 сдвигов frozen |
| **П1** (мес. 1–3) | Тень: считаем параллельно действующему процессу | Доля планов, которые диспетчер не отверг сразу |
| **П2** (мес. 3–6) | Операционный участок одного РЭС | KPI заказчика по ресурсам; **не** SAIDI, пока нет их модели последствий |

Смета гранта ₽4 млн — в `02` §6 (статьи 410-ПП: ФОТ, испытания, адаптация площадки, ПНР, аренда стенда, страхование). Транши 50/50.

### 3.1. План Б: данные не дадут

| Если | Тогда |
|---|---|
| ДЗО не выгружает 10 позиций из `22` | Остаёмся на синтетическом РЭС; просим письмо о заинтересованности без данных |
| Выгрузка без окон ПЛ / бригад | П0 на неполных данных с явным списком дыр чекера; не имитировать полноту |
| Отказ по КИИ / ПДн | Обезличивание до передачи; стенд вне SCADA; без этого пилот не стартует — так и пишем |
| Грант 410-ПП не дадут | Платный контур ₽4–20 млн или НИОКР Россетей |

Не заполнять анкету фразой «пилот уже идёт».
