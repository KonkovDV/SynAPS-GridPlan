# Pilot protocol (future customer data)

## Positioning (allowed)

Scenario oriented to network-operator tasks: automate planning, improve ТОиР
programme justification, replan when asset state changes. **Not** integrated with
any DSO systems unless separately evidenced.

## Gate checklist before any pilot claim

1. Sanitized customer extract with provenance `customer_data`
2. Written constraint catalogue agreed with a domain engineer
3. Independent feasibility on a held-out week
4. Frozen-commitment policy agreed
5. Comparison vs incumbent process (not only GREED)
6. Explicit non-claims list attached to every slide

Until then: `claim_level=experiment` only.
