## 3. Осознанно отложено (не демо-путь Марафона)

Зафиксированы субагентами, но не блокируют GREED / repair / CP-SAT-30 / FIFO:

- ALNS frozen/setup guards неполны на редких composition-путях (вне demo).
- Возможность «подделать» frozen-план через прямой вызов солвера без portfolio
  (продуктовый путь идёт через `plan_*` / `repair_schedule`).
- Fan-in/fan-out приоритеты (L1 из RT-19) — ограничение модели SynAPS `Order`.
- ЗИП как concurrent pool (L5) — без изменений семантики.
