# 07 — Демо-сценарии (ядро: ремонтная кампания сети)

> Главный для Дня заказчика — **A: синтетический РЭС «Северный»** (тот же контур, что README / `jury_report.md`).
> Не обещать 400 работ: в фикстуре **55 работ, 7 бригад, 39 активов, 85 окон**.
> Команды — из пакета GridPlan, не «голый» `python -m synaps`.

## Сценарий A — главный: РЭС «Северный»

**История для зала (60 секунд):**  
«Район 110/35/10 кВ, открытые нормы длительностей — не выгрузка ДЗО. 55 работ, 7 бригад. Календарный FIFO ставит всех и ломает правила: 107 жёстких нарушений. GREED ставит тех же 55 и проходит независимую проверку. Согласованную заявку ПЛ замораживаем — срочная не двигает её. Тот же вход — тот же план».

| Элемент | Смысл на РЭС |
|---|---|
| Актив | ПС / линия / ячейка |
| Работа | ТО, ремонт, дефект |
| Бригада | квалификация, home base |
| Окно | заявка ПЛ |
| Frozen | уже согласованная строка ПЛ |
| Ban | «не отключать два аппарата сразу» (явное правило, не N-1) |
| ЗИП | расходный остаток |

**Ход демо (как в README):**

```bash
python -m pip install -e ".[dev]"
python benchmark/jury_benchmark.py
```

Не запускать `synthesize --mode small --seed 42` + GREED как «зелёное» демо:
exit 2 / `ASSET_OVERLAP` — ожидаемый fail-closed (GREED не моделирует
эксклюзивность актива). Для маленькой фикстуры с exit 0: `--seed 12`.

На защите показывать:

1. `benchmark/results/jury_report.md` — FIFO 107 / GREED 0, версия 0.1.1, пин `bd09d13`.
2. Строка «проверка: да» только при нуле нарушений.
3. Scenario B в том же контуре: freeze ПЛ, срочная, frozen на месте.
4. Запас: скринкаст 3 мин (offline), тот же отчёт.

**KPI на слайде:** 107 vs 0; 0 сдвигов frozen; не SAIDI.

Не говорить «400 работ» и не запускать `tiny_3x3` из upstream как демо продукта.

## Сценарий B — тираж: блок ГРЭС (ЭЛ5, не центр заявки)

Только если в зале ЭЛ5. Фикстура `gres-block` (синтетика, `not_live_el5`):

```bash
python -m synaps_gridplan synthesize --mode gres-block --seed 42 -o gres.json
python -m synaps_gridplan solve gres.json --solver GREED -o gres_result.json
```

Не называть Конаковскую ГРЭС и не показывать как пилот ЭЛ5.

## Сценарий C — «Авария / перепланирование»

Тот же РЭС: срыв окна / новая срочная → локальный ремонт графика. Frozen ПЛ не двигаются. Это ресурсный replan, не восстановление схемы сети.

## Техтребования

- Ноутбук offline: пакет установлен заранее (`pip install -e ".[dev]"`).
- Запас: 3-мин скринкаст + `jury_report.md`.
- Не тянуть в демо 50k/500k cover-прогоны движка — другой домен.
