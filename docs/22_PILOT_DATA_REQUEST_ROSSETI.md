# Данные, необходимые от «Россетей» для пилота GridPlan

> Локальный документ заявки (`docs/` gitignored). Не утверждает наличие доступа.

GridPlan — **слой оптимизации**, не замена АСУ ТОиР / 1С / CIM / диспетчерских
систем. Для пилота нужна выгрузка (API, файлы или витрина), а не доступ в SCADA.

## Обязательный минимум

| # | Данные | Зачем | Формат (пример) |
|---|--------|-------|-----------------|
| 1 | Реестр оборудования (активы) | объекты планирования | код, класс, площадка, напряжение |
| 2 | Перечень работ ТОиР / дефектов | jobs | длительность (норма), вид, приоритет |
| 3 | Бригады и квалификации / группы ЭБ | eligibility | состав, допуска, home base |
| 4 | Календарь доступности бригад | capacity | смены, отпуска, аварии |
| 5 | Согласованные окна / заявки ПЛ | outage windows | start/end, asset, статус |
| 6 | Нормативы длительности | duration_min | СТО / внутренние нормы |
| 7 | Остатки ЗИП + даты поставок | spare constraints | qty, warehouse, ETA |
| 8 | Матрица переездов или GIS-proxy | setup / travel | мин между площадками |
| 9 | Запреты совмещения отключений | `simultaneous_outage_bans` | пары активов + причина |
| 10 | Критерии оценки плана | objective weights | makespan / tardiness / недоотпуск* |

\* Недоотпуск / SAIDI — только если заказчик даёт **свою** модель последствий;
иначе GridPlan считает только proxy risk и явные bans.

## Желательно для усиления пилота

- ИТС / PoF / consequence scores (customer_risk_model)
- Frozen commitments уже согласованных ПЛ
- История факта выполнения (для калибровки длительностей)
- Справочник совместимых замен ЗИП
- Контакт владельца процесса планирования ТОиР

## Явно не требуется на пилоте v1

- Прямой доступ к SCADA / телеметрии
- Полный CIM с расчётом режимов (это этап после `network_constraints`)
- Замена мобильного приложения бригад

## Выход пилота

1. Verified schedule (JSON + markdown report)  
2. Diff при аварийном событии  
3. Сравнение FIFO / эвристика / CP-SAT (где размер позволяет)  
4. Список нарушенных входных ограничений (если данные противоречивы)  
5. Методика расчёта эффекта — **не** готовые ₽ без факта
